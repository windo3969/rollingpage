# 디자인 가이드

기준 시안: [reference.webp](reference.webp) — 모든 화면 작업 시 이 시안의 톤을 따른다.
색상 값은 시안에서 눈으로 추출한 근사치이며, 디자인 단계에서 확정한다.

## 무드
따뜻하고 손으로 쓴 듯한 감성. 크림색 종이 위에 파스텔 포인트, 손글씨 제목, 작은 하트·별 장식.
"안전함"은 차갑게 표현하지 않고, 아이콘 + 짧은 문구로 부드럽게 안심시킨다.

## 색상
| 토큰 | 값(근사) | 용도 |
|---|---|---|
| `background` | `#FBF6F0` | 페이지 배경 (따뜻한 크림) |
| `surface` | `#FFFFFF` | 카드, 입력창 |
| `paper` | `#FDF3EA` | 롤링페이퍼 카드/종이 느낌 영역 |
| `primary` | `#E58A8E` | 주요 버튼(방 만들기, 작성 완료), 하트 |
| `primary-soft` | `#F4C2C2` | 비활성 버튼, 연한 강조 |
| `text` | `#3D3632` | 본문 (순검정 대신 따뜻한 짙은 회갈색) |
| `text-muted` | `#8C817A` | 보조 설명, placeholder |
| `border` | `#EDE4DC` | 입력창·카드 테두리 |
| `success` | `#4FA89A` 계열 | "작성 완료" 배지, 진행률 바 |
| `pastel-*` | 핑크 `#FBE3E3` / 노랑 `#FCEBC7` / 민트 `#DFF1E6` / 하늘 `#DDE9F7` | 단계 아이콘 원형 배경, 마스킹테이프, 장식 |

## 타이포그래피
- **손글씨 (제목·강조·카드 속 메시지)**: 한글 손글씨체 (후보: Google Fonts `Gaegu`, `Nanum Pen Script`, `Hi Melody`)
- **영문 로고·장식** ("Rolling Paper", "How it works", "Happy Birthday"): 스크립트체 (후보: `Dancing Script`, `Caveat`)
- **본문·폼·버튼**: 깔끔한 산세리프 (후보: `Pretendard`)
- 손글씨체는 제목/메시지 카드에만. 폼 라벨·안내 문구·버튼은 가독성을 위해 산세리프.

## 컴포넌트 규칙
- **버튼**: 완전 둥근 pill 형태(`rounded-full`), primary 배경 + 흰 글자. 비활성은 `primary-soft`.
- **입력창**: 흰 배경, 얇은 `border`, 둥근 모서리(약 8px), 연한 placeholder.
- **카드**: 흰색 또는 `paper` 배경, 큰 둥근 모서리, 아주 옅은 그림자.
- **메시지 카드(결과 페이지)**: 종이 질감, 살짝 기울기(±1~2°), 상단 마스킹테이프, 손글씨 본문, 하단 `- 이름 -` 서명. 사진은 폴라로이드 느낌.
- **장식**: 하트(♡), 반짝이 별, 손으로 그린 밑줄 — 과하지 않게 여백에만.
- **배지**: 작은 pill. "작성 완료"는 민트, "미작성"은 핑크.
- **아이콘**: 가는 선(line) 아이콘, 파스텔 원형 배경 위에.
- **신뢰 표시**: 자물쇠/차단 아이콘 + 짧은 문구 ("검색엔진 차단", "랜덤 URL", "사진 비공개 저장").

## 화면별 참고 (시안 기준)
| 화면 | 시안 요소 |
|---|---|
| 랜딩 `/` | 튤립·카드 사진 히어로, 손글씨 헤드라인, "지금 방 만들기 →" 버튼, 4단계 안내(How it works), 안전 기능 3가지 |
| 방 만들기 `/new` | 폼 + 오른쪽(데스크톱)에 생일 카드 일러스트. 모바일은 폼만 |
| 작성 `/r/[id]` | 상단 글감 힌트 박스, 메시지 입력(글자 수 표시), 점선 사진 업로드 영역(1장), 하단 작성 완료 버튼 |
| 결과 | 손글씨 제목 + 메시지 카드 그리드(폴라로이드 사진 포함) |
| 주최자 `/host/[token]` | 방 요약 카드(썸네일, 진행중 배지, 마감일, 공유 링크 복사), 참여 진행률 바, 참여자 명단/미작성자 리마인드 탭 |

## 시안과 기획이 다른 부분 (기획 우선)
- 헤더의 **"로그인"** 메뉴: MVP는 로그인 없음 → 표시하지 않는다.
- 작성 화면 **"임시저장"** 버튼: MVP 범위 밖 → 생략.
- 작성 글자 수 **0/500**: DB 제한은 2000자. 결과물 레이아웃을 위해 500자로 줄일지는 6단계에서 결정.
- 주최자 페이지의 **참여자 명단·진행률·리마인드**: Phase 2 기능 → Phase 1에서는 방 요약 + 링크만.
- 시안의 짧은 URL(`rollingpaper.kr/abc123`)은 예시일 뿐, 실제 방 ID는 21자 랜덤 문자열을 유지한다.
